# Order Management with Alpaca

## Overview

The Order Management system has been updated to work exclusively with Alpaca Markets. The OrderManager class now directly integrates with AlpacaConnection to handle all order lifecycle operations.

## Architecture

```
OrderManager
├── AlpacaConnection (Direct integration)
├── Order Lifecycle Management
│   ├── Order Placement
│   ├── Order Tracking
│   ├── Order Cancellation
│   └── Fill Processing
└── Event Publishing
    ├── Order Events
    ├── Fill Events
    └── Status Updates
```

## Key Changes

### Direct Alpaca Integration

The OrderManager now works directly with AlpacaConnection:

```python
from src.alpaca_connection import AlpacaConnection
from src.order_manager import OrderManager

# Create connection
connection = AlpacaConnection(config)
await connection.connect()

# Create order manager
order_manager = OrderManager(
    connection=connection,
    event_bus=event_bus
)
```

### Order ID Handling

Alpaca uses string-based client order IDs:

- Format: `ORD_<timestamp>_<sequence>`
- Example: `ORD_1703123456_1`
- Generated by AlpacaConnection

### Order Types

Supported Alpaca order types:

| Order Type | Description |
|------------|-------------|
| MKT | Market order |
| LMT | Limit order |
| STP | Stop order |
| STP_LMT | Stop limit order |

### Order Status

Alpaca order statuses:

| Status | Description |
|--------|-------------|
| new | Order accepted |
| accepted | Routed to exchange |
| pending_new | Pending submission |
| partially_filled | Partial execution |
| filled | Complete execution |
| canceled | Order canceled |
| rejected | Order rejected |
| expired | Order expired |

## Usage Examples

### Placing Orders

```python
# Market order
order_manager.place_order(
    symbol="AAPL",
    quantity=100,
    side="BUY",
    order_type="MKT"
)

# Limit order
order_manager.place_order(
    symbol="AAPL",
    quantity=100,
    side="BUY",
    order_type="LMT",
    limit_price=150.00
)

# Stop order
order_manager.place_order(
    symbol="AAPL",
    quantity=100,
    side="SELL",
    order_type="STP",
    stop_price=145.00
)
```

### Canceling Orders

```python
# Cancel by order ID
order_manager.cancel_order(order_id="ORD_1703123456_1")

# Cancel all orders for a symbol
order_manager.cancel_all_orders(symbol="AAPL")
```

### Order Events

The OrderManager publishes events through the EventBus:

```python
# Order placed event
{
    "event_type": "order.placed",
    "order_id": "ORD_1703123456_1",
    "symbol": "AAPL",
    "quantity": 100,
    "side": "BUY",
    "order_type": "MKT"
}

# Order filled event
{
    "event_type": "order.filled",
    "order_id": "ORD_1703123456_1",
    "symbol": "AAPL",
    "filled_qty": 100,
    "fill_price": 150.25
}

# Order canceled event
{
    "event_type": "order.canceled",
    "order_id": "ORD_1703123456_1",
    "symbol": "AAPL"
}
```

## Integration with Trading System

### Main Trading App

The main trading app initializes OrderManager with Alpaca:

```python
class TradingApp:
    async def initialize(self):
        # Load configuration
        self.config = BrokerConfig.from_env()
        
        # Create Alpaca connection
        self.connection = AlpacaConnection(self.config.alpaca)
        await self.connection.connect()
        
        # Initialize order manager
        self.order_manager = OrderManager(
            connection=self.connection,
            event_bus=self.event_bus
        )
```

### Rule Engine Integration

The RuleEngine uses OrderManager for trade execution:

```python
# In rule action
self.order_manager.place_order(
    symbol=self.symbol,
    quantity=self.quantity,
    side=self.side,
    order_type=self.order_type
)
```

## Error Handling

### Common Errors

1. **Insufficient Buying Power**
   - Check account balance
   - Reduce position size

2. **Invalid Symbol**
   - Verify symbol exists
   - Check symbol format

3. **Market Closed**
   - Check market hours
   - Enable extended hours if needed

### Error Events

```python
{

}
```
